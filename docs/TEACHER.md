# Watch a decision change the colony
For ages 7–12, with an adult available to explain unfamiliar words.

1. Start paused. Ask which reserve is falling and why.
2. Open Buildings, place a solar panel, then compare an oxygen extractor on low and high ground using the Air lens.
3. Predict the resource change, then press Play. Pause and compare the prediction with the resource bar.
4. Repeat with a different plan. Ask what the new plan cost.

Use the same seed, difficulty and site when comparing runs. The current setup still generates its seed automatically; Settings shows it. A class-seed entry field is not implemented yet.

Real observations, simplified geographic models and fictional game balances are different. The lens labels and existing science screens explain those distinctions. This game is not an engineering safety tool.

No account, advertising or tracking. Optional NASA refresh sends a request to NASA. Saved missions remain in this browser's local storage. Do not enter student names as colony names. Clearing browser data removes saved missions.
