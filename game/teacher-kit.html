Run a short session

Allow about 15–20 minutes including discussion. The child-play target is 8–12 minutes and still needs observation. Reading and talking never consume a game day. Offer reading help to younger players and use the map instrument if walking is awkward.

Use shared mission code DRB1-20261114-0. Keep the same code and version for comparisons. A new first attempt needs a fresh test profile; preserve existing player saves. The game labels repeat play as practice.

Look for three ideas

  1. Machines share limited power, supplies and workers.
  2. An observation can change a preparation or shelter choice.
  3. A delayed Earth reply means the crew needs a local plan.
WhenNeutral promptWatch for
Before play“Two machines need power, but there is not enough for both. What might happen?”Initial explanation, without coaching.
Preparation“What do you expect your choice to change?”Cost, storage, generation or worker reasoning.
InstrumentLet them predict, inspect both readings and choose.Using evidence or revising a prediction.
Radio pause“Earth cannot reply yet. What can the crew decide here?”Planning locally; no assumption that radio loss removes sunlight.
Comparison“One preparation changed. What happened to your supplies?”Reasoning from actual outcomes.

If help is needed, ask what the current instruction says, point to the relevant meter, then demonstrate only if necessary. Record the help. A shortage pauses the mission and offers retry; it is an opportunity to revise the plan.

Transfer questions

Ask before showing this answer guide. Record the first answer and any revision separately. A wrong prediction can be useful learning.

AskEvidence of understanding
“You want more food. What else should you check before turning on another greenhouse?”Links extra food to power, water or a worker; checks shared capacity.
“The battery is full, but dust keeps blocking sunlight. Can it make new energy forever?”Distinguishes storage from generation; expects depletion and proposes a response.
“A machine stops and Earth will reply later. What could the crew do safely while waiting?”Uses current readings, reserves and a local plan.

Optional rubric: 0 = unrelated guess or no explanation; 1 = names a relevant resource/action; 2 = connects it to a consequence. This is a formative discussion aid, not a validated test. Fame is game feedback, not a learning grade.

Keep the science clear

  • A dosimeter studies ionizing radiation. It is not a thermometer.
  • The 100/30 instrument readings are simulated relative indices, not live Mars dose measurements or NASA protection ratings.
  • MOLA supplies global height information; local terrain detail and machine output are simplified models.
  • The cached Horizons light time informs the reply queue. The message clock is compressed; a Martian day is not twenty minutes.
  • Radio loss does not remove sunlight. Dust and radiation exercises have separate schedules.
  • Game costs, crop times, bonuses and resource units are tuned for learning.
